# 인공지능 얼굴상 테스트

사진 한 장으로 보는 얼굴상 테스트 모음입니다. 사진은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.

**https://dypark9606.github.io/aifacetest/**

## 기능

| 탭 | 내용 |
|---|---|
| 인공지능 외모점수 | 얼굴 점수를 상위 10% ~ 하위 10% 로 판정 |
| 닮은꼴 연예인 | 남자 161명 / 여자 160명 중 가장 닮은 사람 |
| 동물상 테스트 | 강아지·고양이·토끼·공룡·곰·원숭이 (남) / 강아지·고양이·토끼·사슴·여우 (여) |
| 개그맨 개그우먼 | 개그맨 136명 / 개그우먼 53명 |
| 일진 테스트 | 일진상인지 모범생상인지 |
| 부자상 테스트 | 부자들의 얼굴과 얼마나 닮았는지 |
| 커플궁합 매칭도 | 두 사람 사진으로 보는 매칭도 |
| 사주팔자 | 생년월일시로 뽑는 네 기둥과 오행 |
| 신년운세 | 올해 기운이 나에게 오는 방식으로 보는 총운·재물·애정·건강 |

연예인 사진은 앱에서 직접 띄우지 않고 나무위키 링크로만 연결합니다.

## 직접 돌려보기

정적 사이트지만 AI 모델을 `fetch` 로 읽기 때문에 **로컬 서버가 필요합니다.**
파일을 더블클릭하면 동작하지 않습니다.

```bash
python3 -m http.server 8899
# http://localhost:8899/index.html
```

`retrain/README.md` 를 보세요. 사진 폴더만 넣으면 명령 두 줄로 인물이 늘어납니다.
