# 새 탭 아이디어 (재학습 없이 가능한 것 위주)

중고생 사용자를 겨냥. **기존 모델을 그대로 재활용**하므로 사진 수집도 학습도 필요 없다.
지금 탭이 9개라 12개까지는 상단 탭바가 버틴다(그 이상은 스크롤 처리 필요).

## 1. 내가 들어갈 아이돌 그룹 ★ 추천

기존 `AI_star_m` / `AI_star_w` 결과를 그룹으로 바꿔 보여준다.
매핑표는 `retrain/idol_groups.json` 에 만들어 뒀다 — **50명 / 34개 그룹**, 모델 라벨과 대조 완료.

> "당신은 **엑소**에 들어갈 얼굴입니다. 백현 자리를 노려보세요."

- 필요한 것: 새 HTML 1개 + 매핑 조회. **모델 추가 없음.**
- 중고생 반응이 제일 좋을 소재.
- 그룹에 안 걸리는 인물이 나오면 "솔로로 데뷔할 상" 으로 처리하면 자연스럽다.

## 2. 우리 반 얼굴 순위 (여러 명 한 번에)

사진을 여러 장 올리면 `AI_handsome` 모델로 점수를 매겨 줄을 세운다.

- 필요한 것: 다중 업로드 UI. 모델은 이미 있다.
- **주의**: 친구들끼리 외모 순위를 매기는 건 놀림거리가 되기 쉽다.
  점수 대신 "고양이상 / 강아지상" 같은 **유형 분류로 줄 세우는 편**이 안전하다.

## 3. 얼굴 궁합 (친구편)

지금 `Sec5_couple` 은 연인 궁합인데, 같은 모델로 "친구 궁합 / 형제 같은 정도"를
만들 수 있다. 결과 문구만 다르게 쓰면 된다.

- 필요한 것: 문구 세트 1벌. **코드 재사용.**

## 4. 오늘의 얼굴 운세

`Sec6_saju` 의 사주 로직 + 날짜를 섞어 매일 다른 결과를 준다.
**매일 다시 열 이유**가 생겨서 재방문율(=광고 노출)이 올라간다.

- 필요한 것: 날짜 시드 + 문구 세트. 모델 불필요.

## 5. 닮은꼴 랭킹 공유 카드

결과를 이미지 카드로 만들어 공유 시트로 내보낸다(이미 `@capacitor/share` 가 들어 있다).

- 필요한 것: canvas 로 카드 그리기.
- **신규 유입 효과가 제일 큰 기능.** 광고보다 이게 먼저일 수도 있다.

## 재학습이 필요한 것 (사진이 있어야 함)

- 최신 아이돌 추가 → 인물당 얼굴 사진 15~20장 필요.
  `retrain/prep_faces.py` 에 폴더째 넣으면 자르기·품질검사·중복제거까지 자동이다.
- **지금 있는 인물 중 사진이 부족한 사람부터 채우는 게 체감 정확도는 더 오른다.**
  새 인물을 늘리면 클래스가 많아져 오히려 헷갈릴 수 있다.
